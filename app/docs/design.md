# Design system

The UI follows the supplied WhatsApp references screen by screen (home, material selection, item details, slot confirmation, partner assigned/tracking, digital invoice, refer & earn, price list), adapted to Green Dhaka's Bangladeshi market and the DOCX business rules.

| Token | Value / use |
| --- | --- |
| Forest | `#155E43` · hero cards and strong brand surfaces |
| Green | `#14875A` · actions, active navigation, money |
| Mint | `#E5F4EB` · status, verification and fee progress |
| Lime | `#D7EFAC` · primary hero contrast and leaf mark |
| Background | `#F4F7F5` · cool off-white |
| Ink | `#16261F` · text |
| Muted | `#6F7D76` · supporting text |
| Border | `#E2E9E5` · separators and cards |
| Corners | 14–24 dp, circular status/control accents |
| Type | Native system fonts; 28/35 dp page title, 20 dp sections, 14/21 dp body |
| Spacing | 22 dp page inset; 20 dp section gap; 12 dp row gap |

Original SVG illustrations represent paper bundles, plastic bottles, metal, electronics, glass and rubber; the recycling-bag hero and leaf mark use the same palette. Android adaptive and iOS app icons are included.

Seller screens: home, market/search/filter, material selection, item quantities/notes/photos, schedule/address/fee review, tracking/OTP/final weight review, invoice/rating/PDF, order history/reorder, credit/referrals, profile/language, addresses, waitlist, support, notifications and connection settings.

Partner screens: onboarding, private NID/portrait upload, online status/current dispatch location, expiring offers, active jobs, departure/arrival/weighing/photos, cash/OTP settlement, customer rating and settlement/commission history.

Admin screens: sign-in, overview, pickups/details/assignment/disputes, partner verification, price publishing/history, catalogue, credit refunds, waitlist, configuration and audit history. Browser layout adapts to desktop and phone widths.

Review images are in `screenshots/`. They are captures of the actual implementation. Demo values and development OTP are intentionally labelled.
